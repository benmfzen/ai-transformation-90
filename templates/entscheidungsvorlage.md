# Template: GF-Entscheidungsvorlage (Tag 30 / 60 / 90)

**Einsatz:** Die drei Meilenstein-Reviews. Immer dieselbe Struktur: **1 Seite Ergebnis, 1 Seite Plan, 1 Seite Budget** — vorab verschickt, im Termin wird entschieden, nicht präsentiert. Jede Vorlage endet mit Beschlussvorschlägen zum Ankreuzen; „Kenntnisnahme" ist kein zulässiges Ergebnis.

---

## Seite 1 — Ergebnis (was ist seit dem letzten Meilenstein passiert)

| | |
|---|---|
| **Kernaussage** | Ein Satz. („Kundenservice und Vertrieb sind die klaren Pilot-Kandidaten" / „2 von 3 Piloten über Ziel, einer skaliert mit angepasstem Scope") |
| **Belege** | 3–5 Zahlen mit Baseline-Vergleich, keine Prosa |
| **Was nicht geklappt hat** | Ehrlich, mit Ursache — steht VOR den Erfolgen, wenn es die Entscheidung beeinflusst |
| **Gelernt** | Max. 3 Punkte, nur was die nächste Phase ändert |

*Tag-30-Füllung:* Impact-Matrix als Bild + Champion-Shortlist mit Begründung.
*Tag-60-Füllung:* Pro Pilot eine Zeile: Zielmetrik, Baseline, Ergebnis, Charter erfüllt ja/nein.
*Tag-90-Füllung:* Validierter Jahreswert je skaliertem Pilot + Adoption + was die Org jetzt kann, was sie an Tag 0 nicht konnte.

## Seite 2 — Plan (was als Nächstes passiert)

| | |
|---|---|
| **Vorschlag** | Der empfohlene Weg in 3 Sätzen |
| **Alternativen geprüft** | 1–2 verworfene Optionen mit je einem Satz Grund (zeigt: es gab eine Wahl) |
| **Meilensteine** | Nächste 3–5 Termine mit Deliverable |
| **Risiken** | Top 3 mit Gegenmaßnahme |
| **Abhängigkeiten von der GF** | Was nur ihr entscheiden/freiräumen könnt |

*Tag-30:* die 3 Piloten mit Charter-Eckdaten. *Tag-60:* Rollout-Plan + Welle 2. *Tag-90:* 12-Monats-Roadmap + Betriebsmodell.

## Seite 3 — Budget & Beschluss

| Position | Einmalig | Laufend p.a. | Anmerkung |
|---|---|---|---|
| Tooling/Lizenzen | | | |
| Externe Unterstützung | | | |
| Interne Kapazität (FTE) | | | konservativ, Adoption < 100 % |
| **Summe** | | | gegen validierten Wert stellen |

**Beschlussvorschläge** (ankreuzen, Abweichungen im Protokoll):

- [ ] Beschluss 1: … *(z.B. „Die drei Piloten P1–P3 starten am … mit Budget …")*
- [ ] Beschluss 2: …
- [ ] Beschluss 3: …

Protokoll: Entscheidung, Abweichung vom Vorschlag, offene Punkte mit Owner + Datum — noch am selben Tag an alle Teilnehmer.

---

**Regeln:** Vorlage 48h vor dem Termin verschicken. Keine neuen Zahlen im Termin, die nicht in der Vorlage stehen. Wenn eine Entscheidung vertagt wird: neuen Termin im Raum festmachen (siehe [Warnsignale](../playbook/01-phase-1-verstehen.md#abbruch-warnsignale-in-phase-1) — eine vertagte Tag-30-Entscheidung ist ein Programm-Risiko, kein Kalenderproblem).
