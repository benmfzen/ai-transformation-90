# Template: Pilot-Charter (verbindlich, max. 2 Seiten)

**Einsatz:** Vor jedem Pilotstart von Champion, Programmleitung und Sponsor unterschrieben. Der Charter ist ab Start eingefroren — Scope-Erweiterungen sind Phase-3-Material, keine Pilot-Änderungen. Umdefinieren der Metrik nach enttäuschenden Zwischenständen ist damit ausgeschlossen.

| Rahmen | |
|---|---|
| **Champion** | Name (Abteilungs-Head) |
| **Pilotteam** | 3–5 Personen, freiwillig, namentlich |
| **Laufzeit** | Start–Ende (max. 4 Wochen aktiver Betrieb) |

## Ziel & Messung

| | |
|---|---|
| **Zielmetrik** | Eine Metrik, klar definiert (z.B. Ø-Bearbeitungszeit pro Standardticket) |
| **Baseline** | Gemessener Ist-Wert + Messzeitraum + Messmethode |
| **Zielwert** | z.B. −30 % gegenüber Baseline |
| **Messung im Pilot** | Wer misst wie oft, auf Team-Ebene (nicht pro Person — keine Leistungskontrolle!) |
| **Nebenmetriken** | z.B. Qualität (Stichproben), Akzeptanz (Kurzumfrage Woche 2 & 4) |

## Abbruchkriterium

Der Pilot wird **vorzeitig gestoppt**, wenn: (mind. eines definieren)

- z.B. nach 2 Wochen < 50 % des Teams das Tool überhaupt nutzt
- z.B. Qualitäts-Stichprobe > X % inhaltliche Fehler zeigt
- ein Datenschutz-/Sicherheitsvorfall eintritt (sofortiger Stopp, immer)

*Ein gestoppter Pilot ist ein Erfolg des Systems: billig gelernt statt teuer skaliert.*

## Entscheidungslogik am Pilot-Ende (Tag 60)

| Ergebnis | Entscheidung |
|---|---|
| Zielwert erreicht, Akzeptanz ok | **Skalieren** → Rollout-Plan in Phase 3 |
| Teilerfolg mit klarer Ursache | **Anpassen & 2 Wochen verlängern** (einmalig) |
| Zielwert verfehlt / Abbruchkriterium | **Stoppen** + Lessons Learned dokumentieren |
